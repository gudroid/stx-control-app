# STX Control (app Android) — @guucds

App para controlar processadores Stetsom STX pelo Bluetooth, com player do pendrive, regulagens e voltímetro.

- A cada envio para este repositório, o GitHub gera o APK sozinho (aba **Actions**).
- O APK mais novo fica sempre em: **Releases → Latest → STX-Control.apk**.
- A tela do app fica em `app/src/main/assets/www/index.html` (mesmo arquivo do site).
